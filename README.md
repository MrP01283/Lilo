# Лила — демонстрационный интерфейс библиотеки

React-прототип для читателя: главная страница, каталог, карточки книг, очередь бронирования, избранное, выдачи, уведомления, профиль и информационные страницы. Все данные демонстрационные; сервер и база данных не требуются.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

На Windows можно дважды нажать `start.bat` в этой папке. Скрипт запустит локальный сервер и покажет адрес страницы.

```powershell
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173/`). Для проверки производственной сборки: `npm run build`.

Избранное, бронирования, профиль и уведомления сохраняются в `localStorage` браузера. Чтобы вернуть исходные демонстрационные сценарии, удалите данные сайта для локального адреса в браузере.

Шрифты хранятся в `public/fonts`, поэтому оформление не требует доступа к Google Fonts при запуске. Тексты лицензий находятся рядом с файлами шрифтов.

## Что показать на защите

На главной есть блок «Попробуйте в демо» с прямыми ссылками на доступную книгу, новую бронь, уже оформленную очередь и действующие выдачи. Каталог поддерживает поиск, фильтры и сортировку. Бронь оформляется через форму; её можно отменить в личном кабинете.
